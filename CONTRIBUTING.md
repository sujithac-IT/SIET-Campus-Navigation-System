# 🤝 Contributing Guidelines — Smart Campus Navigator

## Code Standards
- All code must pass `npx tsc --noEmit` cleanly without type assertions or `any` bypasses.
- Components must use modern Tailwind CSS utilities and Lucide icons.
- All new campus features must support offline caching and ARIA accessibility standards.

## Commit Guidelines
Use standard conventional commit prefixes:
- `feat:` New features or UI components
- `fix:` Bug fixes or pathfinding corrections
- `docs:` Documentation updates
- `refactor:` Code improvements without functionality changes
